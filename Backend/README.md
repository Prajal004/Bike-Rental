# 🏍️ BikeFlow - Motorcycle Rental System

## 📋 Description
A comprehensive motorcycle rental platform with Shop Owner and Customer features.

## 🚀 Features

### For Shop Owners
- Shop registration and management
- Bike inventory management
- Booking management
- Document verification
- Payment tracking

### For Customers
- Browse available bikes
- Book motorcycles
- Document upload (Citizenship, License)
- Payment integration (eSewa, Khalti, FonePay)
- SOS alerts

### For Riders
- Accept delivery requests
- Real-time tracking
- Earnings management

## 🛠️ Tech Stack
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT
- **Payment**: eSewa, Khalti, FonePay
- **SMS**: Twilio / Custom SMS Gateway
