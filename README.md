# 🏍️ Motorcycle Rental App - Nepal

Complete Motorcycle Rental Application with Payment, Referral, SOS, and Nepali Language Support.

---

## 📱 Features

### 1. 💳 Payment Integration (Nepal)
- eSewa Wallet
- Khalti Wallet  
- Fonepay QR
- Cash on Pickup

### 2. 🤝 Referral System
- Referral code sharing
- Wallet credits (Rs 50 per referral)
- Discount for new users (Rs 100 off)

### 3. 🇳🇵 Nepali Language
- Full Nepali UI
- English toggle option
- Localized content

### 4. 🆘 SOS Emergency
- One-tap SOS button
- Live location sharing
- Emergency contacts notification
- Police/Ambulance calling

### 5. 📍 Maps & Location
- Google Maps integration
- Pickup location selection
- Return location selection
- Nearby motorcycle finder

---

## 🛠️ Tech Stack

| Part | Technology |
|------|------------|
| Frontend | Flutter (Dart) |
| Backend | Node.js + Express |
| Database | MongoDB |
| Payment | eSewa, Khalti, Fonepay |
| Maps | Google Maps API |
| SMS | Sparrow SMS (Nepal) |
